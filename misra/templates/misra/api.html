API

miSRA API

Read miSRA data from your own scripts: experiment metadata, read statistics, expression matrices, the experiments where a miRNA is highest, and more. No registration is needed.

Basics

  • All endpoints are GET requests below {{ base }}.
  • Parameters go in the URL: {{ base }}expression-matrix?exp=SRX2716515,SRX2716516&format=tsv. Lists are comma-separated.
  • Names of miRNAs and tRNAs are case-sensitive and follow the reference (MirGeneDB: Hsa-Mir-21_5p, miRBase: hsa-miR-21-5p); the feature-names endpoint lists them.
  • The data are updated with each miSRA build; database tells the date.

Choosing experiments

Endpoints marked experiments accept these parameters. They can be combined: accessions or a taxon define the set, filters and text narrow it down. Any filtered view of the browse page becomes an API call by copying its query string.

Output and errors

{% include "misra/_api_params.html" with params=format_params %}
  • JSON results include not_found when some accessions you asked for are not in miSRA.
  • Errors come with an HTTP status (400 wrong parameter, 404 not found, 413 too many experiments, 429 too many requests) and a JSON body: {"error": "…", "help": "link to this page"}.
  • Limits: expression and seed matrices up to {{ matrix_limit|intcomma }} experiments per request, per-experiment details up to {{ detail_limit|intcomma }}; larger sets with the Expression matrix tool. {% if rate %}At most {{ rate }} requests per minute per address.{% endif %}

From scripts

Shell

curl "{{ base }}top-experiments?feature=Hsa-Mir-122_5p&limit=5"
curl -o matrix.tsv "{{ base }}expression-matrix?study=SRP103227&value=read_count&format=tsv"

Python

import pandas as pd, requests

api = "{{ base }}"
# metadata of all female human blood experiments with at least 5 million reads
exps = pd.read_csv(api + "experiments?organism=Homo sapiens&tissue=blood&sex=female"
                         "&min_read_count=5000000&format=tsv", sep="\t")
# their miRNA expression (RPM)
r = requests.get(api + "expression-matrix", params={"exp": ",".join(exps.exp_id[:500])}).json()
matrix = pd.DataFrame(r["data"], index=r["features"], columns=r["experiments"])
